# 调试菜单组件

## 功能说明

调试菜单是一个位于页面右下角的浮动组件，用于实时调整游戏状态的所有数值。

## 主要功能

### 1. **实时数值调整**
- 所有 `gameState` 参数都可以实时调整
- 支持 +/- 按钮快速调整
- 支持直接输入数值
- 自动同步到全局游戏状态

### 2. **参数控制**
- **日期**: 日期选择器
- **行动点**: 0-10 范围，步进 1
- **金钱**: 无上限，步进 10,000
- **案件数量**: 无上限，步进 1
- **逮捕人数**: 无上限，步进 1
- **犯罪率**: 0-100% 范围，步进 1
- **逮捕准确率**: 0-100% 范围，步进 1
- **社区信任度**: 0-100% 范围，步进 1

### 3. **重置功能**
- 一键重置所有数据到初始配置
- 使用 `GameStateManager.resetState()` 方法
- 自动同步到页面显示

### 4. **界面控制**
- 可隐藏/显示调试菜单
- 可展开/收起调试面板
- 状态摘要显示

## 使用方法

### 1. 基本使用
```tsx
import { DebugMenu } from '@/components/debug'

// 在页面中使用
<DebugMenu onStateChange={setGameState} />
```

### 2. 状态同步
调试菜单会自动同步到全局游戏状态，无需手动管理。

### 3. 重置数据
点击红色重置按钮即可将所有数据恢复到 `gameConfig.ts` 中的初始值。

## 技术特点

- **实时同步**: 使用 `useEffect` 和定时器确保状态同步
- **类型安全**: 完整的 TypeScript 类型支持
- **响应式设计**: 适配不同屏幕尺寸
- **性能优化**: 合理的更新频率和状态管理
- **用户友好**: 直观的界面和操作反馈

## 注意事项

- 调试菜单仅在开发环境中使用
- 数值调整会立即生效并影响游戏状态
- 重置功能会清除所有当前进度
- 建议在测试时谨慎使用重置功能
